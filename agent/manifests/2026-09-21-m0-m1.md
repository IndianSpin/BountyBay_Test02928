# Context Manifest — M0 bootstrap + M1 pure domain

## Objective

Bootstrap the Bounty Bay monorepo per DEC-020 / 06_ARCHITECTURE.md §3 and implement
the pure deterministic game domain (Milestones 0–1 of 16_IMPLEMENTATION_SEQUENCE.md):
amount rules, the full match state machine, economy math, server-authoritative time,
role-scoped projection, and a headless simulator with seeded strategy agents.

## Relevant rule / requirement IDs

GR-001…GR-022; GE-001…GE-010; DEC-020; 06_ARCHITECTURE.md §2–§7, §11; 07_DATA_MODEL.md;
08_API_CONTRACTS.md (error codes); SI-001/SI-002/SI-004; 15_SIMULATION_VALIDATION_PLAN.md §1–§2, §5.

matchmaking/rating (OQ-001), M7 analytics, M8 AI opponents (OQ-008), M9 async (OQ-004),
M10 moderation. No real-money behavior anywhere (DEC-019).

## Tests required

Unit valid/invalid/boundary per rule; property/fuzz invariants (15_ §5); determinism;
RV-leak penetration tests; simulator matrix across 4 strategy agents × 2 scenario scales.

## Result

- Changed files: as listed above (monorepo scaffold + packages + apps + docs relocation).
- Behavior implemented: full deterministic match lifecycle (ready → active → deal /
  no-deal / aborted), concession costs, clock multipliers, economy settlement,
  disconnect freezing, role-scoped views with structural RV isolation.
- Tests: 120 passing (8 files) — `pnpm test`; `pnpm typecheck`, `pnpm lint`,
  `pnpm build` (Next 16.3.5 production build) all green. Simulator batch CLI runs.
- Unresolved issues: none blocking; OQ-001…OQ-014 remain open by design and are untouched.
- Spec ambiguities encountered:
  1. Walk-away is limited to the turn owner (GR-012 "active player" read with the
     glossary's definition; consistent with UF-02 step 9). Non-owner walk-away would
     need a spec change.
  2. When the turn transfers to a disconnected player, the domain pauses immediately
     (derived from GR-014/GR-015: a disconnected player must not accumulate decision
     time). Server-layer debounce/abandonment windows are intentionally outside the
     domain (OQ-009).
  3. RV reveal applies to all terminal states including ABORTED (07_DATA_MODEL:
     "After match completion RV is revealable").
- No-spec-change confirmation: no canonical document was modified; only relocated.
  No decision-log updates (nothing decided — all values are the documented v0.1
  provisional defaults from 03_GAME_ECONOMY.md §2).
