# Context Manifest — M5 UX polish + replay

## Objective

Milestone 5 of 16_IMPLEMENTATION_SEQUENCE.md: polish the live experience and
add the replay screen. Per 09_UI_DESIGN_SYSTEM: ARIA live announcements for
new offers and turn changes, 44px targets, visible focus states, reduced
motion, grouped number formatting, per-second clock projection (preview only,
GR-016); opponent handles on the board; a ZOPA visualization on the result
screen (UF-08); and a dedicated replay screen reconstructing the full event
stream (PRD-010: offers, chat, clock ownership changes, accept/walk-away,
result).

## Relevant rule / requirement IDs

09_UI_DESIGN_SYSTEM.md; PRD-010; UF-08; GR-016 (client projections are
previews only); GR-018 (reveal); SI-001 (participant-only replay — the API
403s everyone else); 08_API_CONTRACTS (events endpoint).
