clipped by .lm-world overflow:hidden; desktop 1440×900 sliced the
bottom band. Re-fit into both reference viewports; PV-Mobile intent
(the interface shrinks to what the current state needs) as the design

the dominant overflow driver: 436px desktop / 362px mobile); mobile

axes + fullPage mobile captures.

**Measured:** mobile world 844/844 worst-case (my turn) — was +368px;
desktop 900/900 — was +90px. Remaining page-level scroll in dev =
the layout's dev auth banner (~32px), absent in production
(documented in the spec comment).

green (fresh captures in design-sandbox/screenshots/bb232/) · full
