Bounty Bay Royale · Phase 3 review

Two ways to stage the deal

Same visual language. Same rules. Same numbers. Two substantially different compositions for the live match screen, rendered for comparison.

The design read: a competitive 1v1 game for deal-minded players, in a playful-premium dark fantastical-marketplace language. The world is playful. The numbers are ruthless. These mocks use placeholder artwork and static data; the chosen direction is built for real in Phase 3 with live state, motion, and sound hooks.

Direction A THE ARENA

The negotiation as a PvP battlefield. Opponents face each other across a central asset; offers square off with the gap between them; resources anchor to each combatant; turn ownership is loud.

How it reads

2-second comprehensionStrong. Whose move and who wants what are spatial, not labeled.
Game feelStrong. Opposition is visceral; offers feel like positions.
Mobile translationStrong. The vertical battlefield stacks naturally into a phone.
Offers clarityGood. Plates are clear but smaller than the table's.
Scenario identityWeakest point. The asset is a small center medallion between the fighters.
Room for chatThin strip. Usable, but table talk feels like an afterthought.
Resource visibilityStrong. HUDs anchor to each player.
DistinctivenessGood, but symmetrical PvP framing is a well-worn game convention.
Verdict: the most immediately game-like, at the cost of the scenario's presence - and the scenario is what the deal is about.

Direction B THE DEAL TABLE

The asset is the centerpiece. Offers arrive as plates on a shared table with the gap between them; players sit at the table's edges; chat is table talk; the action dock sits on the table's edge.

How it reads

2-second comprehensionStrong. The question "what are we negotiating over?" answers first.
Game feelStrong. A private deal over a prized object; plates feel like plays.
Mobile translationStrong. The table compresses into a compact stage with a persistent dock.
Offers clarityExcellent. Large plates, gap centered between them.
Scenario identityExcellent. The asset leads the screen with name, art, and story.
Room for chatExcellent. Dedicated table-talk panel; persuasion has a home.
Resource visibilityGood. HUD sits under the table, beside the dock.
DistinctivenessStrong. A deal table is a Bounty Bay-specific stage, not a generic battleground.
Verdict: matches the product's priorities directly - scenario first, then offers and gap, then turn and resources.

Recommendation: The Deal Table

Why

The brief's own priority order decides it. The screen must answer "what are we negotiating over?" first, and only the table gives the asset genuine presence. Offers and the gap land on one shared stage where both players look at the same thing - which is what a negotiation actually is. Table talk gives persuasion a home instead of a strip.

  • Scenario identity: the asset leads the screen.
  • Offers and gap: one shared stage, largest plates, centered gap.
  • Chat: a real panel, not an afterthought.
  • Arena's best move carries over: the turn banner and plate glows make turn ownership loud.
  • Mobile keeps the persistent bottom dock so the turn is never a scroll away.
