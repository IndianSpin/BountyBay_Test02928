Why ZIPPA RATCHET reads as an opponent, not a mascot

ArchetypeThe Inventor-Trader (Human). Every visual choice below serves this role at the negotiation table.
Signature readSilhouette + prop (the wrench) + one dominant gesture is enough to identify ZIPPA RATCHET at a glance, per the shared cast4 hand-and-prop system.
Shape languageDistinct dominant shape (see full-body sheet) keeps every cast member readable in a lineup, never a re-skin of another character.
Expression rangeThe same 8-expression target set as GoldenOtter (amused / skeptical / fake-friendly / pleased / unimpressed / deal-ready / triumphant / irritated), re-authored for this anatomy rather than reused wholesale.
Scene integrationComposited with the shared scene-light system; appears at the shared match table lit identically to every other opponent so the cast feels like one game.
StatusDECIDED — built to the approved GoldenOtter v4 standard; no open product questions on this character.
