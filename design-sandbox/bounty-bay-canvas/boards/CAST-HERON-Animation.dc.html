8 — Animation key-pose sheet

Six states, ready for layered-sprite tweening in code

Idle

Default while nothing is happening; loops with a slow accent every few cycles.

Listening

While you compose or speak; settles and tracks.

Speaking

Mouth-shape beats synced to voice/text reveal.

Weak offer

A small concession barely moves them.

No deal

The table won’t close; irritation shows.

Closing

The signature gesture at the moment of the deal.

Runtime is layered sprites tweened in code (the approved GoldenOtter animation decision), so each state above is a target pose the tween interpolates toward, not a pre-rendered frame sequence.
